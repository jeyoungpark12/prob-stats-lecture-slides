확률변수: 결과에 숫자를 붙이는 규칙

표본공간 S

X = 앞면이 나온 횟수

X의 값

(앞, 앞)

(앞, 뒤)

(뒤, 앞)

(뒤, 뒤)

2

1

0

표본공간의 각 근원사건에 실수 하나를 대응시키는 관계 = 확률변수

예: 동전 한 개를 두 번 던지는 시행

동전을 두 번 던지면 결과는 네 가지입니다. 이 결과 자체는 숫자가 아니지만, '앞면이 몇 번 나왔나'라는 규칙을 정하면 각 결과가 0, 1, 2라는 숫자로 바뀝니다. 이렇게 결과에 숫자를 붙이는 규칙이 확률변수입니다. (앞, 뒤)와 (뒤, 앞)이 모두 1로 가는 점을 강조해 주세요. 그래서 X=1의 확률이 가장 큽니다.
