확률질량함수의 두 가지 성질

성질 1

0 ≤ pᵢ ≤ 1

각 확률은 0 이상 1 이하

성질 2

p₁ + p₂ + ⋯ + pₙ = 1

모든 확률의 합은 1

그림으로 보는 성질 2: 확률 막대를 이어 붙이면 정확히 전체 1

P(X=0) = 1/4

P(X=1) = 1/2

P(X=2) = 1/4

참고: X가 a 이상 b 이하일 확률의 기호 P(a ≤ X ≤ b)

확률질량함수가 되려면 두 가지가 필요합니다. 각 확률이 0과 1 사이여야 하고, 모두 더하면 1이어야 합니다. 아래 막대처럼 확률들을 이어 붙이면 전체 길이가 꼭 1이 됩니다. 문제에서 미지수 k를 구할 때 대부분 이 '합이 1' 성질을 씁니다.
