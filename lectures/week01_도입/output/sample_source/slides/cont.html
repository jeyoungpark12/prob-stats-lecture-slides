X (대기 시간, 분)

예: 10분 간격 지하철 대기 시간 X

값의 범위
0 ≤ X ≤ 10 의 모든 실수

확률밀도함수 f(x)
f(x) ≥ 0, 전체 넓이 1

한 점의 확률
P(X = a) = 0

셀 수 없는 값 → 막대 대신 곡선(함수), 합 대신 넓이

대기 시간처럼 3분, 3.1분, 3.14분… 끝없이 잘게 나눌 수 있는 값은 셀 수 없습니다. 그래서 막대 대신 함수 그래프를 그리고, 확률은 그래프 아래 넓이로 구합니다. 높이가 1/10, 폭이 10이니 전체 넓이가 1입니다. 예를 들어 3분에서 7분 사이를 기다릴 확률은 4 × 1/10 = 0.4. 폭이 0인 한 점의 넓이는 0이므로 P(X=a)=0입니다. (대기 시간 숫자는 예시이니 교과서의 수치로 바꿔 쓰셔도 됩니다.)
